## 应用用途及已查结果

应用用于本地图片转 PDF 与基础静态 PDF 合并。业务通过系统选择器获取用户选择的文件，先生成私有完整结果，再由用户另存或分享。

- 实际主 APK 的 Android 权限为前台服务、dataSync 前台服务、任务通知和 WAKE_LOCK；另有 AndroidX 的签名级私有 receiver 权限。没有声明 INTERNET、短信、联系人、无障碍服务、设备管理或安装其他 APK 的权限。
- 被报构建确实开启调试，包含导出的 Compose PreviewActivity；这些开发组件在现有 release 对照构建中不包含。尚无证据说明它们就是本次检测的触发原因。
- PDF 依赖为 PdfBox-Android 2.0.27.0。实际 APK 保留 FontBox WindowsFontDirFinder 中两处 Runtime.exec 调用，用于 Windows 字体目录查询；库在 Android vendor 分支选择 Android 字体查找器。业务源码未发现主动调用 Windows 查找器，尚未完成该分支的设备动态跟踪，也不能据此判定检测结论正确或错误。
- 本机 Windows Defender 定向扫描没有产生对应工作区的检测记录；该结果不能替代 vivo 的 Android 检测结论。功能回归通过同样不证明安全。
